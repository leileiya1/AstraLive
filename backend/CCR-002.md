# CCR-002

## Reason

冻结的接口未定义 Avatar prepare、KnowledgeBase index 的执行命令，也未定义 `POST /api/v1/dev/platform-events` 到 AI Runtime 的输入通道。Knowledge 文档请求体同样未定义。Backend 无法在不发明跨模块协议的前提下完成这些异步任务或保证 COMMENT 触发 AI 回复。

## Proposed Change

定义对应 Runtime 命令或平台事件输入通道，以及文档上传的请求结构与状态事件；明确 Job 成功/失败如何反馈给 Go。

## Impact

- Backend
- Runtime
- Frontend
- Integration

## Breaking

NO，新增协议。

## Migration

现有 Mock Avatar prepare 可在 Backend 内即时完成；其他 Job 保持 `PENDING`，直到协议冻结并接入 Worker。文档创建当前返回 `422`。
