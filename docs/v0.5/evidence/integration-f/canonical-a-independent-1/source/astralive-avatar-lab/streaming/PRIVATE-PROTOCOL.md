# Private Worker protocol proposal, revision 1

Only implement after Stage A mechanical, timestamp and continuity review. This does not amend any AstraLive public contract.

MVP transport: a single authenticated bidirectional TCP connection inside verified-key SSH tunnels; Worker binds only 127.0.0.1. A random per-experiment bearer token authenticates the connection in addition to SSH. No public RGB/HTTP inference listener. Framing is two network-order uint32 lengths followed by UTF-8 JSON metadata and binary payload; header <=16 KiB, payload <=2 MiB. A later protobuf/gRPC migration can preserve semantics. gRPC is preferred for deployment; this MVP explicitly does not claim gRPC production readiness.

- Auth: token (never logged), protocol_version=1. Reply has worker_epoch, GPU_WORKER_READY and immutable model_revision/cache_id.
- PrepareAvatar: avatar_id, input_asset_sha256. This experiment exposes only the cached, already-tested official Girl asset; no arbitrary file path from client. Reply has cache_id. Cache key includes model revision, input image SHA256 and inference/preprocessing settings.
- BeginGeneration: monotonically increasing generation_id, cache_id, sample_rate=16000, channels=1, pcm_format=s16le, first_sample_index, output_fps=25. At most one active generation. Caller owns commercial Session and timeline. No reusable ID within a Worker epoch.
- AudioChunk: generation_id, chunk_sequence, first_sample_index, sample_count, final_chunk; binary signed little-endian PCM payload. Contiguous validation. EOF padding is confined to the last incomplete 15360-sample block; emit only valid frames.
- Credit: generation_id, latest_consumed_sequence; initially at most four frames in flight (160 ms), replenish only after actual remote decode/consumption. Committed pose consists of the last nine remotely consumed RGB frames. Unacknowledged old output must never become the next task's motion history.
- VideoPacket: worker_epoch, generation_id, frame_sequence, pts_us, duration_us=40000, codec=h264, width=height=512, keyframe_flag, encode_latency_ms, audio_queue_ms, video_queue_ms, payload bytes. No B frames, GOP 25; new generation creates an encoder and begins with SPS/PPS and an IDR. Receiver recreates its decoder and rejects epoch/generation at receipt and immediately before display/fanout.
- CancelGeneration: atomically invalidate the generation, clear queued audio/frames and unacknowledged pose entries; preserve only last remotely consumed pose. Already submitted CUDA work finishes at a safe boundary and is discarded. A packet already admitted to transport cannot be recalled, so receiver fences are mandatory. No model reload.
- Health: request nonce; reply nonce, ready, epoch, active generation, last completed frame, queue durations and error. RTT uses a single client's monotonic clock. Do not subtract uncalibrated GPU and school-linux monotonic clocks to claim one-way latency.

Receive dispatch must never wait for audio capacity: reject overflow and invalidate the task, allowing cancellation/health to remain responsive. Audio admission credits are reported independently of frame credit. PCM producer/receiver, inference and video encode/consume are separate threads. Audio sample budget 32000 (2 s), one pending inference block <15360 samples, eight-second feature history, video queue 24 (960 ms), network credit four frames; all buffers and kernel/socket limits must be reported. A slow receiver must exert backpressure, not create unbounded recordings or lists.

Loss/health timeout invalidates Worker epoch. A production provider must continue local Lightweight rendering and cannot replay old work on reconnect. This protocol experiment alone does not prove AstraLive fallback, A/V playback, WebRTC/RTMP or browser acceptance.
