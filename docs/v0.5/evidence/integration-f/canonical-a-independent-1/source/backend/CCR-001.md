# CCR-001

## Reason

`control-api.openapi.yaml` 的部分 `components.responses` 和 `components.requestBodies` 与 `components.schemas` 同名（如 `Avatar`、`Voice`、`Product`、`LiveRoom`），在 oapi-codegen v2.5.1 中生成重复 Go 类型名，直接生成失败。

## Proposed Change

将冲突的 response component 重命名为 `AvatarResult` 等名字、request body component 重命名为 `AvatarBody` 等名字，并同步 `$ref`；HTTP 接口和 JSON 均不变。

## Impact

- Backend OpenAPI 代码生成
- 其他使用 response component 名称的生成器

## Breaking

NO（仅组件符号重命名，外部 HTTP 不变）

## Migration

Lead 合并前，Backend 在自身目录保留按该规则生成的本地输入副本；源 Contract 不变。
