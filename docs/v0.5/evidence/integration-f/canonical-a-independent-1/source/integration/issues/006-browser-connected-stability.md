# ISSUE-006: Uninterrupted browser-connected soak

Status: **CLOSED — 30-MINUTE BROWSER-CONNECTED SOAK PASS** on 2026-10-07. Discovered during the production frontend ICE follow-up. ISSUE-005 covers ICE deployment and is closed separately.

Mac Chrome reached `ICE=connected` and `connectionState=connected` through the normal STUN-configured `useLivePreview()` peer. A muted 45-second preflight received 3,010 audio packets and decoded 1,505 video frames, but `totalAudioEnergy` remained 0. The user had intentionally enabled mute to avoid loud playback. After output mute was off, an independent Chrome `AudioContext` clock advanced normally. A subsequent 45-second preflight at 1% browser playback volume, without muting, had increasing positive audio energy and paired browser media for both Runtime cycles; Session Stop passed. [Diagnostic](../evidence/browser-audio-and-host-diagnostic-20261007.md), [quiet preflight media](../evidence/browser-preflight-quiet-45s-media.json), and [Runtime result](../evidence/browser-preflight-quiet-45s-runtime.json).

A later long-run attempt reached about 17 minutes with 28/28 Runtime cycles paired to browser media; the user manually rebooted Ubuntu at approximately 07:59 local time, interrupting that run. The earlier 00:11 and 01:52 boot boundaries were observed, but their causes were not established. Interrupted runs do not count toward the continuous 30-minute gate. [17-minute media](../evidence/browser-soak-17m-host-restart-media.json).

Closure evidence: a fresh ordinary Mac Chrome → Go → Ubuntu Runtime run with the formal frontend STUN build monitored the peer for **1,826 seconds**. All 60 regular `getStats()` samples and all 52 Runtime-cycle samples showed `ICE` and `connectionState` connected. Audio packets/bytes, positive audio energy, video packets and decoded frames increased at every sample. The Runtime completed 52 Speak/COMMENT/Product/XL/FORCE/NONE/Idle cycles with zero errors and Session Stop PASS. The Redis stream contained 1,884 valid events, zero `SESSION_FAILED`/`UTTERANCE_FAILED`, 52 intended interrupts and one `SESSION_ENDED`. All 156 Product Tool calls returned 200. Product facts included XL as an offered size and only aggregate stock; the existing TTS-boundary safety check confirms XL-specific stock is not invented. RSS warmed and fluctuated, with no monotonic increase across the run. [Browser media](../evidence/browser-connected-soak-30m.json), [Runtime run](../evidence/browser-connected-runtime-30m.json), [event and resource audit](../evidence/browser-connected-audit-30m.json), and [XL wording check](../evidence/fact-safety-v1.1.json). Browser playback was 1% and unmuted. Contract remained unchanged; MuseTalk **NOT RUN**.
